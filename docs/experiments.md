# Muon Newton-Schulz 正交化调度对比实验

## 一、研究问题

Muon 优化器通过 Newton-Schulz（NS）迭代将动量矩阵正交化。每次迭代由五次多项式系数 $(a, b, c)$ 定义：$p(\sigma) = a\sigma + b\sigma^3 + c\sigma^5$。不同系数决定了每次迭代将奇异值推向 1 的速度。

在 **T=5 步固定**的前提下，五种系数序列构成一个从慢到快的谱系：

| 策略 | 每步系数 | 收敛速度 |
|------|---------|----------|
| **Vanilla** | 5× $(2.0, -1.5, 0.5)$ | 最慢，标准 NS 迭代 |
| **Manual** | 3× 快速 + 2× 稳定 | 先快后慢 |
| **Fast** | 5× $(3.4445, -4.7750, 2.0315)$ | 最快，Keller Jordan 调优系数 |
| **Polar Express** | 每步动态计算 | 自适应 |
| **AdamW** | 无 | 基线 |

本实验在完全固定的训练栈上对比这五种策略。

| 动量 | 0.95 |
| NS 迭代步数 | **T=5** |

### 各策略系数序列

- **Vanilla**：5 步全用 $(2.0, -1.5, 0.5)$
- **Manual**：前 3 步 $(3.4445, -4.7750, 2.0315)$ + 后 2 步 $(2.0, -1.5, 0.5)$
- **Fast**：5 步全用 $(3.4445, -4.7750, 2.0315)$
- **Polar Express**：`T=5`，`lower_bound=1e-3`，`cushion=0.02`，`safety_factor=0.02`

## 三、总运行量

5 配置 × 3 种子 = **15 轮**

每轮 100M tokens，总计 **1.5B tokens**。

## 四、评估指标

| 维度 | 指标 | 含义 |
|------|------|------|
| 最终效果 | `val/loss`（最终值，各种子间均值与标准差） | 验证损失 |
| 收敛速度 | `val/loss` 随 token 数变化曲线 | 同等预算下谁收敛更快 |
| 计算开销 | `train/step_time_ms`，正交化耗时占比 | 不同策略的墙钟时间 |
| 正交性质量 | `spec/update_orth_error` | $\|U^TU - I\|$ |
| 训练稳定性 | 各种子间 `val/loss` 标准差 | 不同种子下的波动 |

## 五、预期

- **Vanilla**（全慢）收敛最慢、正交质量可能不达标，但计算量最低
- **Fast**（全快）收敛最快，但可能"冲过头"导致正交精度差
- **Manual** 居于两者之间
- **PE** 期望在收敛速度与正交质量间取得最佳平衡，但有额外计算开销
- **AdamW** 作为无正交化的下界参照

## 六、实现说明

当前实现已经对齐这份实验设计，并额外去掉了会干扰解释的竞速遗留：

1. 模型已改为标准 per-layer prenorm Transformer，不再使用参数银行
2. 输出头和损失已改为 tied embedding + 标准 cross-entropy，不再使用 softcap logits
3. 数据已改为固定长度连续 block 采样，不再使用 BOS 对齐 packing
4. Adam 参数现在每步更新，不再使用交错 step trick
