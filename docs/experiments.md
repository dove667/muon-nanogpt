# Muon 系数迭代策略对更新几何与预训练行为的对照实验

## 一、研究问题

本项目研究的核心问题是：在统一训练与优化设置下，不同 Newton-Schulz 系数迭代策略如何改变 Muon 更新矩阵的谱几何，以及这种几何差异如何进一步影响 LLM 预训练的收敛质量与计算表现。

Muon 的关键步骤是对进入优化器更新的矩阵施加五次多项式迭代。若记奇异值为 `σ`，单步迭代可写为

$$
p(\sigma) = a\sigma + b\sigma^3 + c\sigma^5.
$$

因此，系数 `(a,b,c)` 不只是一个实现细节，而是决定奇异值如何被推向目标区间的谱变换规则。不同的系数序列会诱导不同的更新几何：有些策略更激进地逼近半正交结构，有些策略更保守地维持稳定性。本项目的目标正是比较这些系数策略在固定训练栈中的几何效应、优化效应与计算代价。

## 二、实验设计原则

本实验采用严格的控制变量设计。除正交化策略本身外，所有训练、模型、数据与优化器超参数在各组之间保持一致，使得不同实验结果可以被解释为系数迭代策略变化的后果，而不是其他实现因素或超参数扰动的结果。

具体而言，实验固定以下条件：

- 单卡训练，不包含分布式通信或多卡同步因素
- 标准 prenorm Transformer 架构，不引入额外的系统级竞速 trick
- 固定数据源与固定 token 预算
- 固定 batch 结构、序列长度、梯度累积与学习率调度
- Muon 组共享完全一致的动量、学习率、权重衰减与迭代步数
- 随机种子固定为代码常量

在这一设计下，唯一的核心因变量是系数迭代策略本身。

| 项目 | 设定 |
|---|---|

| Newton-Schulz 步数 | `T=5` |

需要特别说明的是，AdamW 的 `0.0006` 与 Muon 的 `0.023` 虽然数值上相差较大，但这并不意味着二者可以直接按标量大小做横向比较。当前配置继承自社区中已被广泛使用的强基线：对于 GPT-2 small / 124M 量级模型，AdamW 取 `6e-4`、Muon 取约 `2e-2` 属于已有经验支持的常见设置。因此，本实验并不是把 AdamW 置于一个显然偏弱的学习率下作为对照。

同时，本实验也不把跨优化器比较解释为“各自完全调参后的极限公平竞赛”。当前设计没有对 AdamW 额外进行系统的学习率 sweep，因此不能完全排除存在更优的 AdamW 超参数配置，从而缩小其与 Muon 的差距。基于这一点，本项目中 AdamW 的角色应理解为一个基线参照，用来给出“无矩阵正交化路径”的性能边界，而不是本课题最核心的研究对象。

## 四、核心比较对象：四种 Muon 系数迭代策略

本项目的核心比较对象并不是“是否使用 Muon”，而是在统一 Muon 框架下四种不同的系数迭代策略。这四种策略共享完全相同的矩阵形状、迭代步数和更新路径，唯一差别在于每一步正交化多项式的系数安排。

### 4.1 Vanilla

Vanilla 使用经典 stable 系数

$$
(2.0, -1.5, 0.5)
$$

连续执行五步。该策略对应较保守的 Newton-Schulz 迭代行为，目标是在较稳定的谱变换下逐步把奇异值推向半正交区域。它是最标准、最容易解释的一种基线 Muon 调度。

### 4.2 Fast

Fast 使用 Keller Jordan 风格的快速系数

$$
(3.4445, -4.7750, 2.0315)
$$

连续执行五步。与 Vanilla 相比，这一策略对奇异值施加更激进的非线性变换，强调更快地压缩谱并逼近目标区域。它代表了“全程快速”的极端策略。

### 4.3 Manual

Manual 是固定的混合调度：前三步使用 Fast 系数，后两步使用 Vanilla 系数。其设计思想是先利用激进系数快速把谱拉入较有利的区域，再用更稳定的系数在后两步收尾。因此，Manual 对应一种典型的“先快后稳”折中方案。

### 4.4 Polar Express

Polar Express 不使用单一固定系数组，而是在每一步根据 lower-bound 假设动态构造五次多项式。当前实验中采用：

- `T=5`
- `lower_bound = 1e-3`
- `cushion = 0.02`
- `safety_factor = 0.02`

这一策略与前三种手工设计 schedule 的根本区别在于，它不是基于固定经验系数，而是基于矩阵符号迭代/极分解近似的谱设计原则逐步生成系数。因此，Polar Express 代表了“理论驱动的自适应调度”。

### 4.5 四种策略的实验地位

这四种策略构成了本项目的核心因变量空间：

- Vanilla：稳定基线
- Fast：激进快速基线
- Manual：经验折中方案
- Polar Express：自适应谱设计方案

它们共同回答的不是“Muon 好不好用”，而是“在 Muon 已经成立的前提下，系数迭代策略如何影响更新矩阵几何与训练行为”。

## 五、实验测量结构

本项目最终形成了三类互补的测量结构，分别对应训练效果、计算成本与谱几何三个维度。

### 5.1 训练效果测量

训练效果用于回答不同系数调度是否会改变最终预训练表现，以及在固定 token 预算下谁的收敛轨迹更优。

核心指标包括：

| 指标 | 含义 |
|---|---|
| `val/loss` 最终值 | 固定预算下的最终验证损失 |
| `val/loss` 最优值 | 训练全过程中的最佳验证损失 |
| `val/loss` vs tokens | 收敛轨迹 |
| `val_auc_tokens` | 验证损失曲线关于 token 轴的平均面积 |

其中，`val_auc_tokens` 用于将整条收敛曲线压缩成单个标量，从而不仅比较最终点，也比较全过程的收敛质量。

### 5.2 计算成本测量

计算成本用于回答不同调度是否带来端到端训练时间差异。

核心指标包括：

| 指标 | 含义 |
|---|---|
| `benchmark/wall_clock_s` | 完整训练 run 的总墙钟时间 |
| `memory/peak_allocated_mb` | 峰值显存占用 |

这里测量的是端到端 wall-clock，而不是单次 kernel 或单次 optimizer step 的微基准。其目的不是分析底层 kernel 性能，而是比较在统一训练脚本中的实际训练成本。

### 5.3 谱几何测量

谱分析用于回答不同调度是否真的改变了 Muon 更新对象的几何结构，以及这种结构变化出现在哪些阶段、哪些模块、哪些对象上。

当前谱分析在 Muon 更新时抓取三类对象：

- `buffer_post`：动量缓存更新后的矩阵
- `g_pre`：进入正交化前的 Nesterov 混合矩阵
- `g_post`：正交化后的矩阵

设当前梯度矩阵为 `G_t`，动量系数为 `m`，动量缓存为 `B_t`，则当前实现中的更新顺序可写为：

$$
B_t = m B_{t-1} + (1-m) G_t
$$

$$
g_{\mathrm{pre},t} = m B_t + (1-m) G_t
$$

$$
g_{\mathrm{post},t} = \mathcal{P}(g_{\mathrm{pre},t})
$$

其中 $\mathcal{P}$ 表示由当前系数调度定义的 Newton-Schulz / quintic 正交化映射。因此，谱分析中的三个对象分别对应：

- $\text{buffer\_post} = B_t$
- $\text{g\_pre} = g_{\mathrm{pre},t}$
- $\text{g\_post} = g_{\mathrm{post},t}$

这一写法强调了谱分析关注的不是抽象的优化器状态，而是 Muon 实际更新路径中的三个关键矩阵：动量累积结果、进入正交化前的混合更新，以及正交化后的实际方向。

对每个对象，记录如下谱统计：

| 指标 | 含义 |
|---|---|
| `sv_min` | 最小奇异值 |
| `sv_max` | 最大奇异值 |
| `sv_std` | 奇异值标准差 |
| `stable_rank` | 稳定秩 |
| `svd_entropy` | 奇异值分布熵 |
| `semi_orth_error` | short-side Gram 上的半正交误差 |

其中，`semi_orth_error` 统一在 short-side Gram 上定义：

- tall 矩阵使用 `X^T X`
- wide 矩阵使用 `X X^T`

这一口径消除了 tall / wide 情况下直接比较 Gram 偏差时的语义混淆。

## 六、谱分析采样方案

谱分析并不对每一步、每个矩阵做完整 SVD，而是采用受控采样方案，以在保证覆盖度的同时控制额外开销。

### 6.1 采样时机

- 每 `10M` train tokens 触发一次谱分析采样
- 在 100M token 训练预算下，共形成 10 个时间采样点

### 6.2 候选矩阵构造

对每个 Muon 参数，先将其真实更新对象 reshape 为矩阵批。随后，不对所有矩阵全部展开，而是在每个参数内部抽取有限代表位置：

- 若矩阵数不超过 3，则全部保留
- 若矩阵数超过 3，则保留首部、中部和尾部位置

这样得到每个采样时刻的候选矩阵集合。

### 6.3 全局采样预算

在每个采样时刻，从全部候选矩阵中再均匀抽取固定数量：

- `spectral_num_matrices = 12`

这 12 个样本在候选顺序上均匀覆盖，因此兼顾了层间与对象间的覆盖率，而不会把谱分析预算集中在少数参数上。

### 6.4 SVD 降采样

对进入 SVD 的矩阵再做尺寸截断：

- `spectral_dim_cap = 1024`

若矩阵行数或列数超过该上限，则按均匀索引下采样后再计算 SVD。这样可以显著降低谱分析成本，同时保留整体奇异值分布形态。

## 七、最终分析对象

综合上述设计，本项目最终比较的不是单个训练 loss 或单个几何统计，而是如下三组相互关联的量：

1. 系数调度对最终验证损失与收敛轨迹的影响
2. 系数调度对端到端训练成本的影响
3. 系数调度对真实更新矩阵谱结构的影响

其中，第 1 项与第 3 项构成本文的核心研究主线；第 2 项以及 AdamW 对照更多承担参考边界的作用，用于帮助解释 Muon 内部不同系数调度的结果应当如何放在更广泛的优化器背景下理解。

因此，这份实验方案书的最终目标可以概括为：

在完全固定的预训练栈中，把 Muon 视为一族由 Newton-Schulz 系数序列参数化的谱变换，并比较这些谱变换如何改变更新矩阵几何，以及这种几何变化如何进一步传导到 LLM 预训练的收敛质量与计算表现。
