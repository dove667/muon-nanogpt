\section{Problem Setup}
\textbf{Problem statement.}
Muon is a recently proposed optimizer that updates matrix parameters by orthogonalizing a momentum-like update direction through a short Newton--Schulz (NS) iteration \citep{jordan2024muon,moddednanogpt2024}. Recent theory has also started to analyze the convergence properties of Muon-style NS updates \citep{kim2026convergence}. In practice, the iteration is controlled by quintic coefficients, so schedule design becomes a spectral design problem rather than a minor implementation detail. This project asks:
\emph{under a fixed transformer pretraining stack, how do different NS coefficient schedules change the spectral geometry of Muon updates, and how does this spectral geometric change affect validation loss and training cost?}

\textbf{Mathematical formulation.}
For a weight matrix $W\in\mathbb{R}^{m\times n}$, AdamW treats the gradient elementwise: each entry is scaled by coordinatewise first- and second-moment statistics. Muon instead treats hidden-layer weights as matrices. Its matrix update is motivated by the polar factor of a momentum-like direction, whose nonzero singular values are all equal to one. For a rectangular matrix $X$, the corresponding target is semi-orthogonality:
\begin{equation}
    X^\top X \approx I_n \quad \text{if } m\ge n,
    \qquad
    X X^\top \approx I_m \quad \text{if } m<n.
\end{equation}
Equivalently, if $X=U\Sigma V^\top$, the ideal semi-orthogonal factor is $UV^\top$.

At a high level, the matrix part of Muon can be summarized as in Algorithm~\ref{alg:muon-high-level}. Non-matrix parameters such as embeddings and normalization parameters are still updated by Adam-style rules, so the defining difference from AdamW lies in how matrix-valued update directions are processed.

\begin{algorithm}[t]
\caption{High-level Muon update for a matrix parameter}
\label{alg:muon-high-level}
\small
\begin{algorithmic}[1]
\State Initialize momentum state $M_t$
\For{$t=1,2,\dots$}
    \State Compute matrix gradient $G_t=\nabla_W \mathcal{L}_t(W_{t-1})$
    \State Update momentum direction $M_t \leftarrow \mu M_{t-1} + G_t$
    \State Obtain a semi-orthogonalized direction $O_t$ by applying Newton--Schulz iteration to $M_t$
    \State Update parameters: $W_t \leftarrow W_{t-1} - \eta_t O_t$
\EndFor
\end{algorithmic}
\end{algorithm}

The reason NS iterations are relevant is that they act directly on singular values. After a normalization step, Muon repeatedly applies a quintic matrix polynomial. If $X_k$ is the matrix after the $k$-th NS iteration, then
\begin{equation}
    X_{k+1} = a_k X_k + b_k X_k X_k^\top X_k + c_k (X_k X_k^\top)^2 X_k,
\end{equation}
or the aspect-ratio-swapped equivalent when the matrix is tall. Since this map preserves the singular vectors and transforms only the singular values, the scalar dynamics are
\begin{equation}
    \sigma_{k+1}=p_k(\sigma_k),\qquad
    p_k(\sigma)=a_k\sigma+b_k\sigma^3+c_k\sigma^5.
\end{equation}
Thus a schedule $\{(a_k,b_k,c_k)\}_{k=1}^{T}$ defines a composed spectral map $p_T$. This is the mathematical object studied in the project: different Muon variants correspond to different ways of moving singular values toward the polar-factor target.

We compare AdamW and four Muon schedule families:
\begin{itemize}
    \item \textbf{stable5}: five stable NS steps $(2.0,-1.5,0.5)$;
    \item \textbf{fast5}: five aggressive Muon steps $(3.4445,-4.7750,2.0315)$;
    \item \textbf{manual}: fast-to-stable schedules, e.g. \texttt{manual\_T5\_f3\_s2} means three fast steps followed by two stable steps;
    \item \textbf{Polar Express}: quintic coefficients generated from matrix-sign theory under a lower-bound assumption on the singular values \citep{amsel2025polar}.
\end{itemize}

\section{Technical Approach}
\textbf{Experimental logic.}
The experiment is designed to isolate the effect of the coefficient schedule. We fix the architecture, data source, token budget, learning-rate schedule, batch structure, and all Muon hyperparameters other than the orthogonalization schedule. AdamW is included as an external baseline because it does not perform NS orthogonalization on matrix parameters. Within the Muon family, the treatment variable is the schedule-defined spectral map.

All experiments are run on one RTX 4090 GPU in BF16 precision using FineWeb-10B tokenized shards \citep{penedo2024fineweb}. The model is an 11-layer pre-norm Transformer with model dimension 768, 6 attention heads, head dimension 128, MLP ratio 4, and sequence length 2048. The total training budget is fixed at 100M tokens, with 131{,}072 tokens per optimizer step, 16 gradient-accumulation steps, 2\% warmup, and cosine decay to 20\% of the peak learning rate.

The optimizer settings are:
\begin{itemize}
    \item AdamW baseline: learning rate $6\times10^{-4}$, $(\beta_1,\beta_2)=(0.9,0.95)$, weight decay $0.1$.
    \item Muon family: matrix learning rate $0.023$, momentum $0.95$, $\beta_2=0.9$, weight decay $1.2$.
\end{itemize}

\textbf{Implemented Muon variant and diagnostics.}
The implementation is a normalized Muon variant with a Nesterov-style lookahead path. Let $G_t$ denote the matrix gradient and $B_t$ the momentum buffer:
\begin{align}
    B_t &= m B_{t-1} + (1-m)G_t,\\
    g_{\mathrm{pre},t} &= mB_t + (1-m)G_t,\\
    g_{\mathrm{post},t} &= \mathcal{P}(g_{\mathrm{pre},t}),
\end{align}
where $\mathcal{P}$ is the schedule-defined NS map. After orthogonalization, the implementation applies a second-moment normalization on the matrix update magnitude before weight decay and the learning-rate step. The measured geometry is therefore the geometry of the real implemented search direction, not of an idealized standalone matrix-sign iteration.

The study uses three run modes. \texttt{train} records validation-loss trajectories, \texttt{benchmark} measures end-to-end wall-clock time with synchronization, and \texttt{spectral} samples real update matrices for SVD diagnostics. For a sampled matrix $X$, we use the short-side semi-orthogonality error
\begin{equation}
    \varepsilon(X)=
    \begin{cases}
        \lVert X^\top X-I\rVert_F, & X \text{ tall or square},\\
        \lVert X X^\top-I\rVert_F, & X \text{ wide}.
    \end{cases}
\end{equation}
This metric is recorded for \texttt{buffer\_post}, \texttt{g\_pre}, and \texttt{g\_post}. We also report validation-loss AUC over tokens and over wall-clock time; these quantities summarize the average validation loss along the whole curve and avoid choosing an arbitrary local slope interval.

\section{Main Results}
\subsection{Coefficient Schedules Change Training Behavior}
Table~\ref{tab:t5} and Figure~\ref{fig:core} compare the core five-step schedules under the same model, data, token budget, and learning-rate schedule. The AdamW baseline is separated from the Muon family, which shows that the matrix orthogonalization path changes pretraining behavior substantially in this setting. Within the Muon family, \texttt{stable5} is much more conservative than the other schedules. The hybrid \texttt{manual\_T5\_f3\_s2} improves over \texttt{stable5}, while \texttt{fast5} and the two Polar Express schedules form the leading group.

The fast Muon coefficients therefore act as more than a numerical implementation choice: they define a more aggressive singular-value transformation that is useful in this pretraining regime.

\subsection{Spectral Maps Explain the Geometry}
The training comparison can be interpreted through the composed scalar map $p_T(\sigma)$. For small singular values, it is useful to record both the mapped value and the amplification ratio
\begin{equation}
    \mathrm{gain}(\sigma)=\frac{p_T(\sigma)}{\sigma}.
\end{equation}
The ratio alone can look large when $\sigma$ is very small, so Table~\ref{tab:map-spectral} reports it together with $p_T(10^{-5})$. For example, \texttt{pe\_T9\_l3e-5} maps $10^{-5}$ to about $0.713$, which corresponds to a gain of about $7.1\times10^4$.

Figure~\ref{fig:maps} shows the same phenomenon across the full interval. \texttt{stable5} is smooth and conservative. \texttt{fast5} amplifies small singular values much more strongly. Deeper manual and Polar Express schedules can push small singular values even closer to the polar target, but the maps also become less monotone and more sensitive to the assumed spectral range. This gives a mathematical explanation for why depth and PE lower bound are meaningful algorithmic choices rather than unrelated hyperparameters.

The SVD diagnostics confirm that these scalar maps affect the real optimizer state. Figure~\ref{fig:spectral} reports semi-orthogonality error for \texttt{buffer\_post}, \texttt{g\_pre}, and \texttt{g\_post}. All Muon schedules reduce error after the NS map, but the reduction is schedule-dependent. In particular, \texttt{manual\_T9\_f4\_s5} and \texttt{pe\_T9\_l3e-5} produce substantially smaller \texttt{g\_post} error than \texttt{fast5}. The module split also shows that the largest schedule-dependent separation appears in attention projection matrices, while MLP matrices are less separated.

\subsection{Geometry Only Partially Transfers to Loss and Cost}
The spectral results show a clear ordering in update geometry, but the validation-loss comparison is more compressed. To check whether the leading schedules remain separated across random seeds, we repeated \texttt{fast5}, \texttt{manual\_T9\_f4\_s5}, and \texttt{pe\_T9\_l3e-5} with seeds 0, 1, and 2. Table~\ref{tab:multiseed} and Figure~\ref{fig:multiseed} show that the mean final losses differ by only about $0.01$. In this 100M-token setting, \texttt{fast5} is the strongest practical baseline, while the geometrically cleaner $T=9$ schedules do not achieve a reliable validation-loss advantage.

The cost comparison gives a similar practical message. At fixed $T=5$, all Muon schedules finish in about 1095--1099 seconds, so changing scalar coefficients has little effect on runtime once the number of NS steps is fixed. AdamW finishes in 1039.73 seconds because it avoids the matrix orthogonalization path. Deeper schedules are more expensive: \texttt{manual\_T9\_f4\_s5} takes 1123.53 seconds and \texttt{pe\_T9\_l3e-5} takes 1119.42 seconds. Thus the main tradeoff is not between different five-step coefficient sequences in wall-clock cost, but between stronger geometric correction and the validation-loss benefit obtained from it.

\subsection{Schedule-Internal Checks}
The internal checks refine the picture without changing the main interpretation. In the manual family, increasing depth from \texttt{manual\_T5\_f3\_s2} to the $T=7$--$10$ range improves final loss from 4.3176 to about 4.29, after which the results lie in a narrow band. The best observed representative point is \texttt{manual\_T7\_f4\_s3} at 4.2873, while \texttt{manual\_T8\_f5\_s3}, \texttt{manual\_T9\_f3\_s6}, \texttt{manual\_T9\_f4\_s5}, and \texttt{manual\_T10\_f5\_s5} are all close. This suggests that extra iterations help the manual family approach the leading schedules, but depth itself is not a monotone quality knob.

Polar Express shows a related sensitivity to the lower-bound parameter. At fixed $T=5$, \texttt{pe\_T5\_l3e-3}, \texttt{pe\_T5\_l1e-3}, \texttt{pe\_T5\_l3e-4}, and \texttt{pe\_T5\_l3e-5} reach final losses 4.2873, 4.2902, 4.2998, and 4.3125 respectively. Since the lower bound determines the singular-value interval used to construct the PE coefficients, this sensitivity is expected from the spectral-map view. Increasing PE depth can repair some low-bound settings, but it also adds computation and does not overturn the multi-seed comparison with \texttt{fast5}.

\section{Conclusion}
This project compared Muon schedules by treating Newton--Schulz coefficients as spectral maps. The first main finding is that coefficient choice matters even at fixed depth: the stable NS schedule is too conservative for this pretraining setting, while the fast Muon coefficients and well-chosen Polar Express schedules give much better token efficiency. This answers the first part of the project question at the training level and is supported by the fixed $T=5$ comparison.

The second finding is geometric. The composed maps $p_T(\sigma)$ explain how different schedules amplify small singular values, and the sampled update matrices show the resulting change in semi-orthogonality error. Deeper manual and PE schedules produce cleaner post-orthogonalization matrices, especially in attention layers. This confirms that the coefficient schedule changes the actual update geometry, not only the notation of the optimizer.

The third finding concerns the connection between geometry and optimization quality. The cleaner updates produced by deeper manual and PE schedules do not reliably reduce final validation loss relative to \texttt{fast5} at the current 100M-token scale. The relationship between semi-orthogonality and language-model loss is therefore not monotone in these experiments. A schedule can make the update closer to a polar factor while still failing to improve the full stochastic training trajectory.

The study is limited to one model scale, one token budget, and a small multi-seed set for representative schedules. Larger runs would be needed to determine whether the attention-layer spectral separation persists at scale. On the mathematical side, the natural next step is to analyze the fixed points, contraction regions, and lower-bound assumptions of the composed quintic maps, then relate those properties to the measured training trajectories.
